Codex Token Meter · macOS 14+

安装
1. 选择符合机器芯片的 ZIP。M 系列使用 Apple Silicon，Intel 机器使用 Intel。
2. 解压，把 Codex Token Meter.app 拖到「应用程序」，再双击打开。应用已包含运行时。
3. 如果 macOS 阻止首次启动，在「系统设置 → 隐私与安全性」查看该应用的提示，确认后选择「仍要打开」。这是临时签名的测试版。
4. 在「系统设置 → 隐私与安全性 → 辅助功能」允许 Codex Token Meter，然后回到 Codex。菜单栏图标里也能打开辅助功能设置。

使用
- 拖动浮条左侧点阵调整位置，点「明细」切换会话和今日用量。
- 查到当前对话的唯一 ID 时使用 ID，其次用窗口标题与本地索引精确匹配。
- 自动跟随无法确定时会说明原因。可通过菜单栏输入聊天链接或 /status 给出的 ID，或恢复自动跟随。
- 默认读取 ~/.codex 下的本机会话与归档。数据保留在本机。CODEX_HOME 可覆盖默认目录。
- 今日用量按北京时间 00:00 起算，包含缓存输入。缺失的用量会显示覆盖提示，无法归属的用量归在「模型未知」。

验证范围
Windows 和 Mac 应用使用相同的会话匹配、去重及统计逻辑。已在 Windows 上构建两个 Mac 架构并核对包内签名和本地统计。原生浮窗、辅助功能权限和多屏跟随仍需要在 Mac 上实机验收。
